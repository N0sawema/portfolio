OGHOSA PORTFOLIO - how to finish and publish

FILES
  index.html      the page
  css/style.css   all styling
  js/main.js      all behaviour and the lists you edit
  assets/         portrait.webp (hero), about.webp (About photo)

THINGS TO FILL IN (all in js/main.js unless noted)
  1. WhatsApp number  - top of the file: const WA='234XXXXXXXXXX' (country code first, no + or spaces)
  2. Brand links      - the WORK list: put TikTok / Instagram video URLs in tt and ig for each brand
  3. Industries       - the WORK list, field t
  4. Tools            - the TOOLS list (names and logos); replace the simple drawn marks with official SVG logos
  5. Bio, services, process text, email address - index.html (search for "Placeholder" and "add address")
  6. Case study text and images - the case study template is built in js/main.js (search "Placeholder")

TO OPEN LOCALLY: double-click index.html.
TO PUBLISH (any static host): drag this whole folder onto Netlify Drop, or upload it to GitHub Pages / Vercel / Cloudflare Pages.
Fonts load from Google Fonts, so the page needs an internet connection to show the intended typeface.
